# 安全评审测试：请勿合并或部署

这里的 JavaScript 代码故意包含安全缺陷，用于测试代码评审工具。部分函数采用安全写法，用于观察误报。

只进行静态评审。文件不是可启动的应用，不提供服务器、路由注册、安装脚本或 CI 自动执行入口。导入仅定义函数；直接运行会报错退出。直接运行保护不限制调用导出的函数，请勿将这些函数接入服务。

接口约定：req.query、req.params、req.body 都是不可信客户端输入。req.user 由可信认证中间件提供。数据库适配器支持参数绑定；没有额外的输入校验、对象权限校验或网络过滤层。res 提供类似 Express 的 json、status、sendFile 方法。

请逐项报告问题所在函数与代码行、输入如何到达危险操作、影响和修复建议。不要执行代码或提交攻击载荷。

详细验收答案单独保存，不放入这个 PR，便于对照检测结果。
